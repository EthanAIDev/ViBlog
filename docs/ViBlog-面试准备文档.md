# ViBlog - 面试准备文档

---

## 项目信息

- **项目名称**：ViBlog -- 纯前端驱动的静态个人技术博客系统
- **项目背景/要解决的问题**：作为一名 AI Agent 开发工程师，我需要一个完全自主可控的个人技术品牌主页，来展示我的技术文章、项目作品和专业形象。市面上的博客框架（如 Hexo、Hugo、WordPress）要么依赖复杂构建工具链，要么部署繁琐，而且定制化成本高。因此我决定从零构建一个**零依赖框架、纯原生 JavaScript + Node.js** 的轻量博客系统，既能体现我的全栈能力，又能作为个人技术品牌的承载平台。
- **核心功能点**：
  1. **文章管理系统** -- Markdown 格式文章编写，自动生成 manifest 索引，支持分类/标签/搜索多维度筛选与分页，详情页集成 Mermaid 图表、KaTeX 数学公式、代码高亮与行号、目录大纲导航
  2. **项目展示系统** -- 支持项目详情（概述/技术栈/实现方案）、图片画廊（含灯箱查看）、GitHub/文档链接，分页浏览
  3. **管理后台** -- 基于 RESTful API 的文章/项目/网站设置的增删改查，Markdown 编辑器（EasyMDE），图片上传与自动命名，Markdown 文件导入解析
  4. **响应式设计 + Shell 导航** -- 桌面端与移动端适配，CSS 变量主题系统，IntersectionObserver 滚动动画与目录高亮，无框架 SPA 风格的 Shell 导航（fetch + DOM 替换）
- **我用到的主要技术/工具**：HTML5 + CSS3 + Vanilla JavaScript (ES5)、Node.js (原生 http/fs/path 模块)、marked.js、highlight.js、KaTeX、Mermaid.js、EasyMDE、JSON 文件存储
- **我的角色和贡献**：独立开发者，负责从架构设计、前端页面、后端 API、管理后台到部署的全流程开发

### 1.2 各层职责与关键组件

| 层级 | 职责 | 关键组件 |
|------|------|----------|
| **表示层** | 页面渲染、用户交互、数据展示 | `script.js`（前端核心引擎）、`styles.css`（样式系统）、5个 HTML 页面、`admin/admin.js`（管理后台） |
| **服务层** | HTTP 请求路由、API 处理、静态文件分发、索引构建 | `server.js`（原生 Node.js HTTP 服务器，约 1074 行）、`build-manifest.js`（索引构建脚本） |
| **数据层** | 内容持久化、配置存储 | JSON 文件系统（`meta.json`、`detail.json`、`manifest.json`、`site-settings.json`）、Markdown 文件（`index.md`）、图片资源 |

**核心设计决策**：
- **不使用数据库**：选择 JSON + Markdown 文件存储，数据即源码，可直接通过 Git 版本管理，无需数据库运维
- **不使用前端框架**：纯原生 JavaScript 实现，包体积接近零，无构建步骤，部署极简
- **不使用 Express/Koa**：使用 Node.js 原生 `http` 模块，完全掌控请求处理流程，深入理解 HTTP 协议
