## 体验目标

访客首先看到一件正在运行、能够回应操作的三维雕塑，然后自然进入作品、文章与关于。画面保留 B 的深海黑蓝、银色金属、烟色玻璃、低位中文标题与展览式留白。

嵌套的三组环分别表达推理、行动与反馈，连接束中的光脉冲表达循环。主视觉只承载通用 Agent 隐喻，个人项目在独立内容区呈现。文章、项目、关于及现有内容路径继续可用。

## 交互约定

| 操作 | 可感知的变化 | 操作结束与边界 |
| --- | --- | --- |
| 默认停留 | 三组环以不同速率缓慢转动，连接束有克制的光脉冲；材质反射随结构变化 | 不设置进入倒计时或强制开场；标题、导航与作品入口立即可用 |
| 移动鼠标 | 镜头产生小幅视差，反射和光影随观察方向变化 | 幅度受限；标题与导航保持稳定；拖动时暂停鼠标跟随 |
| 悬停环或连接点 | 对应部件出现局部轮廓和亮度变化，按需出现一个简短名称 | 移出即收起；不常驻多组标签和解释文字 |
| 按住拖动 | 旋转雕塑，释放后短暂阻尼减速 | 用户操作优先，自动旋转暂缓；从当前姿态恢复，避免突然跳回 |
| 点击一组环 | 选中环展开少量间距并聚焦，一次光脉冲沿其连接传播；只显示一句相关说明 | 再点或 Esc 返回整体；复位入口始终可达；避免拖动结束误触点击 |
| 滚动页面 | 首屏内雕塑逐步展开，三组环的关系变清楚；接近作品区时画面安静退后 | 页面保留自然滚动；反向滚动可恢复，不劫持滚轮或强制停留 |
| 暂停、复位 | 暂停保留当前姿态，复位恢复整体视角并清除选中 | 暂停优先于自动演示，不因移出移入画面而自行取消 |

输入优先级：暂停/减少动态效果偏好 → 用户拖动与点击 → 滚动叙事 → 自动运行。避免多种输入同时争夺同一镜头。

触屏：横向拖动旋转、点击部件聚焦，纵向滑动保留页面滚动。键盘：可访问的部件入口、暂停和复位，Enter/Space 激活、Esc 退出；焦点清晰并在关闭后归还。

## 页面范围

- 首页：全幅主视觉、简短身份与入口，下面进入真实项目与文章；保留简洁主导航。取消旧工厂及其操作说明、五阶段标签和下方详情面板。
- 项目：延续展览章节和大幅真实截图，聚焦作品内容与案例入口。
- 文章：延续深色视觉与字体系，正文采用安静、清晰的阅读列，保留筛选、目录、公式、代码、图表与图片查看。阅读期间不运行三维场景。
- 关于：沿用同一视觉语言，以真实个人内容与现有联系方式组织。
- 不增加经营分析、Token 生成或模拟后台数据，不把三维演示包装为真实 Agent 请求。

## 技术与素材

复用现有 Astro、React、Three.js 与静态内容管线。React 管理暂停、选中、加载等交互状态；独立场景模块管理镜头、几何、材质、拾取、动画和资源释放。保留 WebGPU / WebGL 2 兼容路径。

主雕塑使用可拾取、可分层展开的三维几何与连接束；金属、玻璃、灯光、环境和接地反射共同承担质感。标题、导航、链接与说明使用真实 HTML。原概念图仅用于视觉比对。加载/故障时使用实际三维场景的独立透明截图，叠加不含文字和雕塑的环境素材。

桌面优先保留完整材质；移动端调整镜头构图并降低像素比、折射与阴影成本。三维按需加载，离屏或页面隐藏时停止循环。减少动态效果时关闭自动旋转、视差和滚动空间变化，仍保留即时选中与内容访问。

不预先宣称图像级玻璃反射已可实时达到；第一个阶段重点验证真实场景的材质质量、操作手感与设备负担。

## 制作顺序与验收

1. **可操作首屏样机。** 在独立预览中实现环形雕塑、材质与自动运行，接通悬停、拖动、点击、滚动、暂停和复位；同时提供手机版。先评估与 B 图的构图、光影和质感差异，确认动态手感。
2. **整站改造。** 将确定的首屏接入首页，再统一项目、文章、关于与公共导航、字体、颜色。保留实际内容、静态阅读与旧链接。
3. **收尾与验证。** 按桌面、平板、手机验证视觉与交互；检查加载/图形不可用、键盘、触屏、减少动态效果和离屏暂停。复用并更新项目 Playwright 验收，回归内容功能与所有路由，完成构建检查。

首屏验收必须观察到真实时间变化和输入导致的状态变化，不能只检查 Canvas 是否存在。自动、悬停、拖动、点击、滚动分别核验；暂停应实际冻结自主运动；拖动不得误触选中；反向滚动应可还原；触屏纵向滑动不得被截获。对照批准图检查物体轮廓、材质、标题位置和画面层次。

性能目标在首屏样机测量：桌面力争稳定 60fps，代表性手机力争稳定 30fps；记录测试设备与图形后端。达不到时先降低折射、反射与像素成本，保留构图和交互语义。软件渲染验收不作为真实设备性能结论。
